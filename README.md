# example-go_study

Go 语言学习示例代码，从基础语法开始，每个示例对应一个知识点。

## 环境

- Go 1.26.4

## 目录

| 文件 | 知识点 |
| --- | --- |
| `01.变量定义.go` | 变量定义 |
| `02.输出.go` | 输出 |
| `03.输入.go` | 输入 |
| `04.基本数据类型.go` | 基本数据类型 |
| `05.数组.go` | 数组 |
| `06.切片.go` | 切片 |
| `07.map.go` | map |
| `08.判断语句.go` | 判断语句 |
| `09.for.go` | for 循环 |
| `10.函数.go` | 函数 |
| `version/` | 版本信息常量 |

## 运行

```bash
go run "01.变量定义.go"
```
